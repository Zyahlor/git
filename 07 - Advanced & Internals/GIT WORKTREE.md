### 🎯 Nội dung cần học (theo [[lộ trình]]):
- `git worktree list`
- `git worktree add <path> <branch>`
- `git worktree remove <path>`
- Làm việc trên nhiều branch bằng các thư mục làm việc riêng biệt mà không cần clone lại.
