### 🎯 Nội dung cần học (theo [[lộ trình]]):
- `git blame <file>`: Soi tác giả và commit từng dòng code
- `git grep <pattern>`: Tìm kiếm chuỗi/hàm trong toàn bộ repo
- Tìm commit và tác giả liên quan đến một đoạn code.
