### 🎯 Nội dung cần học (theo [[lộ trình]]):
- `git tag`: Liệt kê tag
- Tạo lightweight tag và annotated tag (`git tag -a v1.0 -m "..."`)
- `git show <tag>`
- `git push origin <tag>` / `git push origin --tags`
- Xóa tag local và remote.
- GitHub Releases và Semantic Versioning (v1.0.0).
