> ⏳ **Nội dung:** Chuẩn bị cập nhật... *(Khi nào học tới đây thì xóa dòng này đi để ghi chép bài học)*

### 🎯 Nội dung cần học (theo [[lộ trình]]):
- `git clean -n`: Xem trước danh sách file rác untracked sẽ bị xóa
- `git clean -f`: Xóa ép các file rác untracked
- `git clean -fd`: Xóa cả file và thư mục rác untracked
- Hiểu nguy cơ xóa file chưa được Git theo dõi.
