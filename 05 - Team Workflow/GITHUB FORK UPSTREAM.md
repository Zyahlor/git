> ⏳ **Nội dung:** Chuẩn bị cập nhật... *(Khi nào học tới đây thì xóa dòng này đi để ghi chép bài học)*

### 🎯 Nội dung cần học (theo [[lộ trình]]):
- Fork repository trên GitHub.
- Phân biệt `origin` và `upstream`.
- Đồng bộ fork với repository gốc (`git remote add upstream <url>`, `git fetch upstream`).
- Đóng góp thay đổi vào repository của người khác.
